Privacy

Last updated: 24 August 2026

This service scans public GitHub repositories and publishes a public report of what it checked and what it found. It requires no account, sets no cookies, and runs no analytics.

Anyone can scan any public GitHub account, including yours, without your involvement. What that means for you is set out under acceptable use, and how to have a report about you deleted is at the bottom of this page.

Data handled

  • The submitted GitHub username, public repository names and identifiers, and immutable commit hashes are stored with the report.
  • Public repository archives are kept only in private worker scratch storage, are never executed, and are deleted before findings are published. Source is not stored in the report database.
  • Reports contain the file path and line number of each match, so a finding can be acted on. They cannot contain source code, snippets, raw matches, secret values, or scanner prose.
  • Email notification is switched off. No address is collected, stored, or sent anywhere. If it is ever switched on, an address is encrypted at rest, is erased after delivery or after the send is given up on, and a keyed abuse-control hash remains only until the report is deleted.
  • Cloudflare may process IP addresses for transport and rate limiting; the application does not persist them.

GitHub receives normal API and archive requests. The AI code review sends source files from your public repositories to OpenRouter. Separately, a twelve line excerpt around each secret-scan finding is sent to Groq and to Google, so that two models from different families can vote on whether it is a false alarm; a finding both reject is removed from the report. Every line where the secret scanner matched a credential is replaced with a redaction marker before a file is sent, and files under directories such as node_modules, dist and .git are never read at all. Those providers may retain or train on what they receive, which is what pays for the free tier this service runs on. The secret scan sends no code anywhere. Optional email, when it is switched on, uses Google Apps Script and Gmail to send the address one public report URL.

Retention and visibility

Anyone with a report URL can view it, and a report names the file and line of each finding. Report URLs are unguessable and are not indexed by search engines. To have a report removed before it expires, contact the operator with the report ID. Active work with no update for 24 hours is failed, its leases are invalidated, and queued email ciphertext is erased. Terminal reports and related metadata are automatically deleted 30 days after their last update.

For removal or privacy requests, contact the operator through the public GitHub profile and include only the report ID. Never post secrets or vulnerable source details publicly.
