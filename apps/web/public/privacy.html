Privacy

Last updated: 17 August 2026

This service scans public GitHub repositories and publishes a source-blind coverage report. It requires no account, sets no cookies, and runs no analytics.

Data handled

  • The submitted GitHub username, public repository names and identifiers, and immutable commit hashes are stored with the report.
  • Public repository archives are kept only in private worker scratch storage, are never executed, and are deleted before findings are published. Source is not stored in the report database.
  • Reports cannot contain source paths, snippets, raw matches, secret values, or scanner prose.
  • If optional email is enabled, the address is encrypted at rest and erased after delivery or final failure. A keyed abuse-control hash remains only until report deletion.
  • Cloudflare may process IP addresses for transport and rate limiting; the application does not persist them.

GitHub receives normal API and archive requests. Optional email uses Google Apps Script and Gmail to send the address one public report URL. No repository source is sent to an email or AI provider. The AI source lane is disabled.

Retention and visibility

Anyone with a report URL can view it. Terminal reports and related metadata are automatically deleted 30 days after their last update. Active work remains until terminal so interrupted jobs can recover safely.

For removal or privacy requests, contact the operator through the public GitHub profile and include only the report ID. Never post secrets or vulnerable source details publicly.
