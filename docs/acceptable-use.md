# Acceptable use

Last updated: 2026-08-17

Use this service only for public GitHub repository security review. Reports are
informational coverage records, not a guarantee that a repository is secure and
not a replacement for a professional assessment.

Do not use the service to disrupt availability, evade rate or quota controls,
scan private or unlawfully obtained data, probe the service itself without
authorization, or deliberately place personal data, credentials, or exploit
payloads into a report workflow. Do not treat a report as permission to exploit
a finding. Disclose security issues responsibly to the repository owner.

The service may refuse, delay, or remove requests to protect its zero-cost
capacity, users, or upstream services. Honest `partial`, `failed`, and
`unsupported` outcomes are part of the product contract.
